# A pasta `marca/`: onde ficam os arquivos que a Forja produz

Toda Forja grava os seus arquivos numa pasta chamada `marca/`:
- **Se o brief está fora de `.cycle/`** (por exemplo `clientes/acme/master-brief.md`), a pasta `marca/` fica ao lado dele: `clientes/acme/marca/`.
- **Se o brief está dentro de `.cycle/`**, a pasta `marca/` fica na raiz da pasta aberta.

Crie a pasta se ela não existir. Antes de criar o primeiro arquivo, diga à pessoa onde ele vai ficar. Ao terminar, liste o caminho de cada arquivo criado.

Os arquivos de uma Forja nunca sobrescrevem os de outra. Se um arquivo com o mesmo nome já existe (uma rodada anterior), pergunte se é para atualizar ou para guardar a versão nova ao lado com a data no nome.

Nada sai da pasta da pessoa: as Forjas não enviam o conteúdo para lugar nenhum.
