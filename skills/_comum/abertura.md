# Abertura comum a todas as Forjas

Na primeira mensagem, além da apresentação própria de cada Forja, diga em linguagem simples:
1. **A versão:** "Forjas v0.1.1".
2. **Quanto tempo leva** (cada Forja diz o seu).
3. **Que arquivos vão aparecer e onde:** o Master Brief (conforme `master-brief.md`) e a pasta `marca/` (conforme `pasta-marca.md`).
4. **O aviso de permissão, uma vez só:** "Vou ler alguns arquivos de apoio que vieram com as Forjas. Na primeira vez, o Claude Code pode pedir permissão para ler uma pasta dentro de `.claude/plugins`. Pode aceitar, inclusive marcando para não perguntar de novo: são só os textos das próprias Forjas."
5. **Que dá para parar e voltar:** o progresso fica salvo (conforme `retomada.md`).

Se a leitura de um arquivo de apoio for negada, não siga sem ele e não invente o que ele diria. Diga qual arquivo faltou, em uma frase, e peça para a pessoa liberar a leitura.
